# 官网字体与风格调整方案（待确认）

参考：https://bigmodel.cn/glm-coding ，2026-09-23 查看。

## 参考依据

- 已用 Chrome 查看首屏和套餐卡片的实际呈现。
- 参考页全局 CSS：`--mainTextColor: #131212`、`--pageBgColor: #f7f8fa`。
- 字体栈为 MiSans、Apple 系统字体、PingFang SC/HK、Helvetica Neue、Helvetica、Microsoft Yahei、Arial、sans-serif。其 MiSans Web 字体声明通过 unicode-range 仅覆盖部分数字与符号，不能据此声称整页中文采用 MiSans。
- 视觉特征：浅灰白底、黑色标题、宽松留白、常规/中等字重、黑色主按钮、白色细边框卡片、少量蓝紫强调及局部柔和渐变。

## 拟实施

1. 全站字体改为系统无衬线栈，中文优先系统苹方/微软雅黑；标题以 500–600 字重为主，正文 400，减少当前 700–750 的粗重感。英文、数字与中文统一基线及行高。暂不引入参考站字体文件。
2. 统一浅灰白背景、近黑标题、中性灰正文、黑色主按钮、少量蓝紫强调；将目前大块深蓝底改成浅色版式。
3. 首页采用更舒展的居中首屏，减少背景图的视觉干扰；两条业务卡片同级展示，局部低饱和渐变区分工业与 OfficeAI。
4. 工业平台、工业方案、OfficeAI、案例、关于我们、演示准备页同步按钮、卡片、标题、导航与页脚样式。
5. 工业 SaaS / 私有化一体机、OfficeAI 全部私有化、数据可信 / Agent 可信 / 环境可信，以及既有页面交互继续作为内容和功能验收项。

## 执行顺序

- 用户确认方案后，先实现首页及全站基础样式，检查桌面与手机实际效果。
- 统一内页及表单样式，完成验收，更新日志并提交 Git。
- 完成后按本会话已有发布流程同步 GitHub 和原 Cloudflare Pages 项目。

## 验收标准

- 在 1440px、390px 视口逐页检查，确保无横向溢出、遮挡、文字截断；目视对照参考页的字体轻重、灰白基调与留白。
- 三层可信和交付形式明确可读，两条业务入口同级且清楚。
- 导航、产品入口、锚点和需求清单生成/导出内容保持正常，键盘焦点与文字对比度可辨识。
- 构建、变更文件 lint、Git diff 检查通过；发布后检查正式域名及二级路由。
